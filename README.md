# Blockchain-Based Patient Health Record Management System

An educational prototype exploring blockchain-based integrity verification and patient-controlled access to health record metadata.

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Smart contracts: Solidity, Hardhat
- Local blockchain: Ganache
- Blockchain integration: ethers.js

## Important Notice

This project is for educational demonstration only. Use synthetic data exclusively. Do not upload real patient records or confidential medical information.

The prototype is not production-ready and must not be used to manage real medical records.

## Project Structure

- `frontend/` — React application
- `backend/` — Express API and encrypted local demo-file handling
- `blockchain/` — Solidity contracts, scripts, and tests
- `docs/` — Project documentation
